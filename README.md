# lyricmp3player
perfect lyric mp3player with batch convert lrc files to song lrc. easy to use have playlist...<p>
<hr>
.support timestamp Lrc format of files use attach batch lrcs converter and drag or open filemanager to put all *.lrc files into it
 <br> and just press convert button will build a single file.<p>
.and the file name is: playlist-lrcText.js move that file to your same directory of index.html. <p>
.besure both filenames (*.mp3, *.jpg, *.lrc)  are the same name and inside your mp3 folder<p>
.index(eng).html and batchMp3convert-to-lrcText.html are english version. you may use this to play.<p>
.support random play, repeat one/ repeat all/ no repeat, gradient green/plain green select/ no highlight, <br>
 lyric window have preset mode can choice. <p>
default is balance mode. and default repeat is play all you can tape any line of lyric then will play begin at that point.<br>
playlist is hide/show mode.<p>
if use in mobile device you have installed some kind like simple server. it is the limit in mobile device for security reason maybe...<p>
wish you enjoy it. Have fun.
