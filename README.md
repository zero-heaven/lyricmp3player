# lyricmp3player
Better lyric Mp3player with batch convert lrc files to song lrc. have playlist...<p>

1. support timestamp Lrc format of files use Batch lrcs converter,  drag or open filemanager to put all *.lrc files into it.<p>
2. the file name is: playlist-lrcText.js move that file to your same directory of index.html. Besure both filenames (*.mp3, *.jpg, *.lrc)  are the same name and inside your mp3 folder<p>
3. index(cht).html / batchMp3convert-to-lrcText(cht).html are chinese Trad version.<p>
4. support Random play, repeat one/ repeat all/ no repeat, lyric line gradient green/plain green select/ no highlight, lyric window have preset mode can choice. 
   Default is balance mode. and default repeat is play all you can tape any line of lyric then will play begin at that point. playlist is hide/show mode.<p>
5. if use in mobile device you have installed simple server or File manager plus: https://play.google.com/store/apps/details?id=com.alphainventor.filemanager the limit in mobile device for security reason maybe...<p>
6. wish you enjoy it. Have fun.
