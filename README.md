# lyricmp3player
perfect lyric mp3player with batch convert lrc files to song lrc. easy to use have playlist...

support timestamp Lrc format of files use attach batch lrcs converter and drag or open filemanager to put all *.lrc files into it and just press convert button will build a single file.
and the file name is: playlist-lrcText.js move that file to your same directory of index.html. 
besure both filenames (*.mp3, *.jpg, *.lrc)  are the same name and inside your mp3 folder
index(eng).html and batchMp3convert-to-lrcText.html are english version. you may use this to play.
support random play, repeat one/ repeat all/ no repeat, gradient green/plain green select/ no highlight, lyric window have preset mode can choice. default is balance mode. and default repeat is play all
you can tape any line of lyric then will play begin at that point.
playlist is hide/show mode.
if use in mobile device you have installed some kind like simple server. it is the limit in mobile device for security reason maybe...
wish you enjoy it. Have fun.
